인스타 팔로우 관리 프로그램
=====================================

내가 팔로우하는데 나를 팔로우하지 않는 사람들을 찾아서
하나씩 자동으로 팔로우 취소해 주는 프로그램입니다.

[ 2026-10-28 바뀐 점 ]
  * 팔로우 후보를 해시태그 대신 트레이너의 「비슷한 계정」에서 모읍니다
    (예전엔 운동하는 일반인이 많아 「트레이너 아님」으로 건너뛰었습니다)
  * 메뉴 10번 「원주 고객 팔로우」가 생겼습니다 - 하루 한 번 누르면 됩니다
  * 언팔 4번을 누르면 전체가 어디까지 됐는지(보류·남김·실패) 먼저 보여 줍니다
  * 인스타가 막으면 그 자리에서 멈추고 며칠 쉬라고 알려 줍니다
  * 하루 한도는 설정.txt 에서 계정에 맞게 직접 정하세요 (프로그램이 막지 않습니다)


-------------------------------------
[ 0. 폴더를 어디에 둘지 - 제일 중요 ]
-------------------------------------

압축을 푼 폴더를 반드시 아래 같은 곳으로 옮기세요.

    C:\인스타관리

C 드라이브를 열고 '인스타관리' 라는 폴더를 새로 만든 다음,
압축 푼 파일들을 그 안에 넣으면 됩니다.


** 아래 위치에서는 프로그램이 돌지 않습니다 **

    X  카카오톡 받은 파일 폴더
    X  OneDrive 안의 폴더 (문서, 바탕화면 포함)
    X  구글 드라이브, 드롭박스 폴더
    X  압축을 풀지 않고 ZIP 안에서 바로 실행

이런 곳에서 실행하면
"지정한 장치, 경로 또는 파일에 액세스할 수 없습니다"
라는 오류가 뜹니다.

이유는 이렇습니다. OneDrive 같은 클라우드 폴더는 파일을 실제로
컴퓨터에 두지 않고 필요할 때 인터넷에서 받아옵니다. 그래서
프로그램이 파일을 읽고 쓰려 할 때 막힙니다.

파일 이름 옆에 빨간 X 표시가 보이면 바로 이 상태입니다.

C 드라이브 아래 일반 폴더로 옮기면 아무 문제 없습니다.
프로그램은 자기 폴더 안에서만 파일을 읽고 씁니다.

-------------------------------------
[ 처음 한 번만 하는 준비 ]
-------------------------------------

1) 위 0번대로 폴더를 옮긴 뒤, '설치.bat' 을 두 번 클릭하세요.
   필요한 것들이 자동으로 깔립니다. (5~10분)
   파이썬이 없다고 나오면 안내대로 파이썬부터 설치하세요.

   * 설치.bat 을 깜빡하고 시작.bat 부터 눌러도 괜찮습니다.
     그 경우 시작.bat 이 알아서 설치를 먼저 해줍니다.

2) 인스타 데이터를 내려받으세요.

   인스타 앱 -> 설정 -> 계정 센터 -> 내 정보 및 권한
            -> 내 정보 다운로드 -> 정보 다운로드 요청

   * '팔로워 및 팔로잉' 만 체크
   * 형식은 반드시 JSON  (HTML 아님! 이거 틀리면 안 됩니다)
   * 기간은 전체

   메일로 다운로드 링크가 옵니다. 보통 5~30분 걸립니다.

3) 받은 ZIP 파일을 이 폴더에 그대로 넣으세요. 압축은 풀지 않아도 됩니다.


-------------------------------------
[ 실행하기 ]
-------------------------------------

'시작.bat' 을 두 번 클릭하면 메뉴가 뜹니다.

   1번 -> 인스타 로그인      (브라우저가 뜨면 직접 로그인)
   2번 -> 내 데이터 불러오기
   3번 -> 판단만 보기        (실제로 아무것도 안 누릅니다)
   4번 -> 언팔 시작

이 순서로 한 번 하고 나면, 그 다음부터는 매일 4번만 누르면 됩니다.

3번은 실제로 아무것도 누르지 않고 "이 사람은 이래서 지운다/남긴다" 만
보여줍니다. 마음껏 돌려보고 마음에 들 때 4번으로 가세요.

[ 꼭 알아두실 것 ]
-------------------------------------

* 하루에 너무 많이 하면 인스타가 계정을 정지시킵니다.
  처음에는 설정을 건드리지 말고 그대로 쓰세요. (하루 100명)

* 프로그램이 도는 동안 뜨는 브라우저 창을 닫지 마세요.
  최소화는 괜찮고, 다른 창에서 문서 작업을 하셔도 됩니다.

* 프로그램이 도는 동안 '진행상황.csv' 를 엑셀로 열지 마세요.
  엑셀이 파일을 잠가서 프로그램이 기록을 못 씁니다.
  진행 상황은 메뉴 8번으로 보시면 됩니다.
  (실수로 열어 두면 프로그램이 안내를 띄우고 멈춥니다.
   엑셀을 닫고 같은 번호를 다시 누르면 이어서 진행됩니다.)

* PC가 절전으로 들어가지 않게 해주세요. 화면만 꺼지는 건 괜찮습니다.

* 멈추고 싶으면 검은 창에서 Ctrl+C 를 누르세요.
  그 시점까지는 다 저장돼 있어서 다음에 이어서 갑니다.

* 인스타는 이런 자동화를 약관으로 금지합니다.
  계정에 문제가 생길 위험은 사용하는 사람이 집니다.

[ 개인정보 - 중요 ]
-------------------------------------

* 비밀번호는 이 프로그램이 절대 다루지 않습니다.
  로그인은 뜨는 브라우저 창에서 본인이 직접 합니다.

* 로그인하고 나면 '크롬프로필' 폴더가 생깁니다.
  여기에 인스타 로그인 정보가 들어 있습니다.

  ** 이 폴더를 쓰기 시작한 뒤에는 남에게 통째로 주지 마세요. **
  '크롬프로필' 폴더가 넘어가면 상대가 내 인스타에 그냥 들어갑니다.

  남에게 줄 때는 처음 받은 압축 파일을 그대로 전달하세요.

* 내 인스타 데이터 ZIP, 진행상황.csv 같은 파일도 개인 기록입니다.
  같이 넘기지 마세요.

[ 이 프로그램이 하는 일 / 안 하는 일 ]
-------------------------------------

하는 일
  - instagram.com 에만 접속합니다. 다른 곳으로는 아무것도 보내지 않습니다.
  - 내 컴퓨터 안에서만 파일을 읽고 씁니다. (이 폴더 안에서만)
  - 인스타 프로필을 열어보고 '팔로우 취소' 또는 '팔로우' 를 누릅니다.

안 하는 일
  - 비밀번호를 묻거나 저장하지 않습니다.
  - 내 정보를 외부로 보내지 않습니다.
  - 다른 폴더의 파일을 건드리거나 지우지 않습니다.
  - 게시물을 올리거나 댓글, DM 을 보내지 않습니다.

들어 있는 파일은 전부 그냥 글자로 된 파일입니다.
메모장으로 열어서 무슨 일을 하는지 직접 읽어보실 수 있습니다.

설치할 때 인터넷에서 받는 것은 두 가지뿐입니다.
  - playwright : 브라우저를 자동으로 움직이는 공개 도구
  - chromium   : 구글 크롬의 공개 버전
둘 다 파이썬 공식 저장소에서 받습니다.
