# 폴더를 어디에 둘 것인가 (제일 먼저)

압축을 푼 폴더를 **C 드라이브 아래 일반 폴더**로 옮기세요.

```
C:\인스타관리
```

## 여기서는 돌지 않습니다

| 안 되는 위치 | 왜 |
|---|---|
| 카카오톡 받은 파일 폴더 | 대부분 OneDrive 아래에 있음 |
| OneDrive 안 (문서·바탕화면 포함) | 파일이 컴퓨터에 실제로 없을 수 있음 |
| 구글 드라이브 · 드롭박스 | 같은 이유 |
| ZIP 압축을 풀지 않고 그 안에서 실행 | 임시 폴더라 기록이 안 남음 |

이런 곳에서 실행하면 이 오류가 뜹니다.

```
지정한 장치, 경로 또는 파일에 액세스할 수 없습니다.
이 항목에 액세스할 수 있는 권한이 없는 것 같습니다.
```

OneDrive 같은 클라우드 폴더는 파일을 실제로 컴퓨터에 두지 않고
필요할 때 받아옵니다. 그래서 프로그램이 파일을 읽고 쓰려 할 때 막힙니다.
**파일 이름 옆에 빨간 X 표시**가 보이면 이 상태입니다.

## 일반 폴더로 옮기면 문제가 없나?

**없습니다.** 오히려 그래야 정상 동작합니다.
프로그램은 자기가 들어 있는 폴더 안에서만 파일을 읽고 씁니다.
위치가 바뀌어도 기능은 똑같습니다.

프로그램은 실행할 때마다 지금 위치를 확인하고,
클라우드 폴더면 경고를 띄웁니다.

# 인스타 팔로우 관리 프로그램

`시작.bat` 을 두 번 누르면 메뉴가 뜹니다. 번호만 고르면 됩니다.

---

## 매일 하는 일

**`시작.bat` → 4번** 이게 전부입니다.

하루 한도까지 언팔하고 알아서 멈춥니다. 껐다 켜도 이어서 갑니다.
멈추고 싶으면 그 창에서 **Ctrl+C**.

팔로우도 같이 하려면 **5번**. 후보가 없으면 알아서 모은 뒤 이어서 팔로우합니다.

> ※ 언팔과 팔로우를 같은 날 많이 돌리지 마세요.
> 인스타는 둘을 같은 행동으로 봅니다.

---

## 메뉴 설명

| 번호 | 하는 일 | 언제 |
|---|---|---|
| 1 | 인스타 로그인 | 처음 1회, 로그인 풀렸을 때 |
| 2 | 내 데이터 불러오기 | 처음 1회, 한두 달 뒤 갱신할 때 |
| 3 | 언팔 - 판단만 보기 | 기준 바꾼 뒤 확인용 |
| **4** | **언팔 시작** | **매일** |
| **5** | **팔로우 시작** | 팔로우도 할 때 |
| 6 | 팔로우 - 판단만 보기 | 기준 바꾼 뒤 확인용 |
| 7 | 후보만 미리 모으기 (비슷한 계정) | 안 해도 됨 (5번이 알아서 함) |
| 8 | 진행 현황 보기 | 아무 때나 (아무것도 실행 안 함) |
| 9 | 2단계 언팔 | 1단계 다 끝난 뒤 |
| **10** | **원주 고객 팔로우** | **하루 한 번** (원주 가게 팔로워 중 지역 사람) |
| 11 | 원주 고객 - 판단만 보기 | 확인용 |
| 12 | 원주 고객 현황 | 아무 때나 |

3번과 6번은 **실제로 아무것도 누르지 않습니다.** 판단만 보여주니 마음껏 돌려보세요.

# 설정 바꾸기

바꿀 게 있으면 **`설정.txt`** 파일 하나만 고치면 됩니다.
메모장으로 열어서 숫자나 단어를 고치고 **저장**하면 끝입니다. 프로그램을 다시 켤 필요도 없습니다.

> 규칙 하나 — `#` 으로 시작하는 줄은 설명입니다. 프로그램이 무시하니 지우지 마세요.

## 1. 속도 바꾸기

파일 위쪽 숫자만 고치면 됩니다.

```
하루_최대 = 150
```

이 숫자가 **가장 중요합니다.** 하루에 실제로 언팔할 사람 수예요.
보류·남김·계정없음은 여기 안 들어갑니다. **진짜 언팔한 수만** 셉니다.

| 하루 처리량 | 판단 |
|---|---|
| 500~700명 | 정지당함 (실제 겪은 수치) |
| 300명 | 넘기지 말 것 |
| 100~300명 | 쓸 수 있는 범위 |
| 100명 | 처음 시작할 때 |

처음 사흘은 100으로, 아무 일 없으면 150 → 200으로 조금씩 올리세요.

```
대기_최소 = 20
대기_최대 = 32
```

계정 사이에 몇 초 쉴지입니다. 지금은 한 명에 약 30초 걸립니다.
**숫자를 키우면 느려지고 안전해집니다.** 줄이면 반대고요.

## 2. 언팔 안 할 계정 정하기

프로그램은 프로필의 **소개글**을 읽어서 판단합니다. 아이디는 안 봅니다.

### 절대 안 건드릴 사람

`[제외계정]` 아래에 **아이디를 한 줄에 하나씩** 적으세요. `@` 는 빼고요.

```
[제외계정]
my_shop_account
best_friend_id
partner_brand
```

### 공부하려고 팔로우한 계정 (영구히 남김)

`[공부단어]` 아래 단어가 소개글에 있으면 **끝까지 안 지웁니다.** 2단계에서도요.

```
[공부단어]
박사
교수
아카데미
official
교육
```

**빼고 싶으면 그 줄을 지우면** 됩니다. `official` 을 더 이상 남기고 싶지 않으면 `official` 줄만 삭제하세요.
**추가하고 싶으면 맨 아래에 한 줄 쓰면** 됩니다.

### 트레이너 계정 (2단계로 미룸)

`[트레이너단어]` 아래 단어가 있으면 **1단계에서는 안 지우고 미뤄둡니다.** 나중에 9번(2단계)에서 정리합니다.

```
[트레이너단어]
트레이너
pt
헬스장
필라테스
```

여기엔 **직업으로 가르치는 사람**만 넣으세요.
`운동`, `다이어트`, `러닝` 같은 취미 단어를 넣으면 일반인까지 다 미뤄집니다.

### 두 목록이 겹치면?

**공부단어가 이깁니다.** "트레이너를 위한 해부학 교육" 같은 계정은
트레이너 단어도 있지만 공부용으로 분류돼 **끝까지 남습니다.**

### 팔로워가 많은 계정

```
큰계정_기준 = 50000
```

팔로워가 이 수 이상이면 안 지웁니다. 원래 맞팔 안 해주는 계정들이니까요.
더 많이 남기려면 숫자를 낮추고(예: 10000), 덜 남기려면 높이세요.

## 3. 바꾼 뒤에는 꼭 확인하세요

설정을 고쳤으면 **3번(판단만 보기)** 을 먼저 돌려보세요.
실제로 아무것도 누르지 않고, 어떻게 판단하는지만 보여줍니다.

```
  406 @ondo.257          [판단만] 언팔 대상 (팔로워 312)
  407 @diet_truth_lab    남김(공부용) 공부용 계정 ('연구소')
  408 @sportworkman      보류(트레이너) 트레이너 계정 ('pt') · 2단계로 보류
```

괄호 안이 **왜 그렇게 판단했는지**입니다. 마음에 안 들면 그 단어를 `설정.txt`에서 고치고 다시 3번.

## 4. 팔로우 설정

```
팔로우_하루_최대 = 100
최소_팔로워 = 50
```

`최소_팔로워` 보다 팔로워가 적으면 유령 계정으로 보고 건너뜁니다.

후보는 **이미 트레이너로 확인된 계정의 「비슷한 계정」 추천**에서 모읍니다 (2026-10-28부터).
내가 팔로우한 트레이너, 언팔 때 보류한 트레이너가 자동으로 「씨앗」이 됩니다.
꼭 넓히고 싶은 트레이너가 있으면 `[씨앗계정]` 칸에 적으세요 (없으면 칸을 새로 만드세요).

```
[씨앗계정]
아는_트레이너_아이디
```

예전 해시태그 방식은 운동하는 일반인 게시물이 대부분이라 「트레이너 아님」으로 줄줄이 건너뛰었습니다.
`[해시태그]` 는 씨앗이 하나도 없을 때만 예비로 씁니다.

## 5. 원주 잠재고객 팔로우 (메뉴 10번)

원주 가게 계정의 **최근 팔로워** 중 진짜 지역 사람만 팔로우하고, 3주 지나도 맞팔 안 한 사람은 조금씩 취소합니다.
센터 계정에서 먼저 써 보며 다듬은 방식입니다. **하루 한 번 10번만 누르면 됩니다.**

- 거르는 것: 가짜·빈 계정, 원주에 매장 없는 온라인·전국 업체, 다른 트레이너·헬스장·필라테스 계정, 이미 나를 팔로우하는 사람
- 원주 가게 사장님·직원 계정은 팔로우합니다 (사람이고 PT 핵심 연령대)
- 다음 날 「어제 누른 팔로우가 실제로 남아 있나」를 몇 명 확인하고, 많이 사라졌으면 그날은 멈춥니다
- 한도: `지역_팔로우_하루`, `지역_언팔_하루` (기본 20). 설정.txt 에 없으면 기본값을 씁니다

## 6. 한도와 「인스타가 막았을 때」

한도는 **계정마다 버티는 양이 달라 프로그램이 막지 않습니다.** 설정.txt 에서 직접 정하세요.
대신 인스타가 막으면(차단 메시지·보안 확인 화면·로그아웃·**눌렀는데 반영 안 됨 2번**) 그 자리에서 멈추고
「며칠 쉬세요」(처음 3일, 7일 안에 두 번째면 14일)라고 알려 줍니다. 쉬는 기간에 다시 켜면 한 번 더 묻고, `y` 를 누르면 진행합니다.

## 7. 언팔 「남은 대상」 숫자 읽는 법

4번을 누르면 맨 위에 작업목록 전체가 어디에 가 있는지 나옵니다.

```
  작업목록 전체 3067명 중
     언팔 완료                     1200
     트레이너라 보류 (9번 2단계 몫)   1500
     남김 · 공부용                  250
     ...
  남은 대상   : 96 명
```

**트레이너라 보류된 사람은 1단계에서 언팔하지 않습니다.** 1단계가 끝나면 9번(2단계)에서 정리합니다.
실패(화면을 못 읽음 등)한 계정은 3번까지 다시 시도합니다.

# 처음 설치할 때

1. **`설치.bat`** 두 번 클릭 — 필요한 것들이 자동으로 깔립니다
2. **`시작.bat`** → **1번** — 브라우저가 뜨면 인스타에 직접 로그인
3. 인스타 데이터 내보내기 ZIP을 이 폴더에 넣고 → **2번**
4. **3번**으로 판단 확인 → **4번**으로 시작

### 인스타 데이터 내보내기 받는 법

```
인스타 설정 → 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드
```

- **"팔로워 및 팔로잉"** 만 체크
- 형식은 반드시 **JSON** (HTML 아님)
- 기간은 전체

메일로 링크가 옵니다. 보통 5~30분.

# 진행 상황 보기

**8번**을 누르면 나옵니다.

```
  전체 대상   :   3420 명
  처리함      :    155 명
     언팔 완료                    115
     보류 · 트레이너(2단계)            8
     남김 · 공부용                   16
     계정 없음                      16
  남음        :   3265 명
```

기록은 `진행상황.csv` 에 쌓입니다. 엑셀로 열어보시면 계정별로 언제 뭘 했는지 다 있습니다.

| 표시 | 뜻 |
|---|---|
| `unfollowed` | 언팔함 |
| `deferred_trainer` | 트레이너 · 2단계에서 처리 예정 |
| `kept_study` | 공부용 · 영구히 남김 |
| `kept_big` | 팔로워 많음 · 영구히 남김 |
| `notfound` | 계정이 사라짐 |

# 2단계는 언제?

1단계(4번)를 **전부 끝낸 뒤**입니다. 8번에서 "남음 0"이 되면 알려줍니다.

그때 **9번**을 누르면 미뤄둔 트레이너 계정들을 정리합니다.
실수 방지를 위해 **`2단계실행`** 이라고 정확히 입력해야 시작됩니다.

돌리기 전에 무엇이 지워질지 꼭 확인하세요.

# 다른 사람에게 줄 때

폴더를 통째로 복사해 주되, **아래는 빼고** 주세요. 개인 기록이라서요.

```
진행상황.csv   팔로우기록.csv   팔로우후보.csv
작업목록.csv   시작지점.txt     크롬프로필 폴더
instagram-...zip
```

받은 사람은 `설치.bat` → `시작.bat` → 1번 → 자기 ZIP 넣고 2번 → 4번 순서로 하면 됩니다.

# 개인정보와 안전

## 로그인 정보가 어디에 있나

로그인하면 **`크롬프로필`** 폴더가 생깁니다. 여기에 인스타 세션이 들어 있습니다.

> **이 폴더를 쓰기 시작한 뒤에는 남에게 통째로 주지 마세요.**
> `크롬프로필` 폴더가 넘어가면 상대가 내 인스타에 바로 들어갈 수 있습니다.
> 남에게 줄 때는 처음 받은 압축 파일을 그대로 전달하세요.

비밀번호 자체는 이 프로그램이 다루지 않습니다. 로그인은 브라우저 창에서 본인이 직접 합니다.

## 이 프로그램이 접속하는 곳

`instagram.com` 과, 시작할 때 새 버전이 있는지 보는 `github.com`(허봇스 공개 저장소) 두 곳입니다.
인스타 기록·로그인 정보를 다른 곳으로 내보내는 것은 없습니다.
파일도 이 폴더 안에서만 읽고 씁니다.

설치할 때 받는 것은 `playwright`(브라우저 자동화 도구)와 `chromium`(크롬 공개 버전)
두 가지이며, 둘 다 파이썬 공식 저장소에서 받습니다.

## 안전장치

프로그램이 스스로 막는 것들입니다.

| 상황 | 동작 |
|---|---|
| 로그인 안 됨 | 한 건도 진행하지 않음 |
| 데이터 안 불러옴 | 팔로우 기능 자체를 막음 (되팔로우 방지) |
| 2단계 실행 | `2단계실행` 을 정확히 입력해야만 시작 |
| 숫자 칸에 이상한 값 | 무시하고 기본값 사용 |
| 하루 한도 도달 | 자동 종료 |

## 되팔로우는 구조적으로 막혀 있습니다

팔로우 기능은 아래를 전부 대조해서 **한 번이라도 걸리면 건너뜁니다.**

- 내가 이미 팔로우 중인 사람 (내보내기 ZIP 기준)
- 언팔 작업으로 건드린 사람
- 언팔 예정 목록에 있는 사람
- 이미 팔로우를 시도한 사람

그래서 방금 정리한 사람을 다시 팔로우하는 일은 생기지 않습니다.
데이터를 안 불러왔으면 이 대조가 불가능하므로 **팔로우 기능이 아예 실행되지 않습니다.**

# 알아두실 것

인스타는 자동화를 약관으로 금지합니다. 계정 위험은 사용하는 사람이 집니다.
하루 한도를 지키는 것이 가장 확실한 안전장치입니다.
