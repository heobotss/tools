★ 먼저 읽어주세요 — 키워드 순위 추적기

우리 센터 키워드의 검색량, 블로그 30위 안 선생님 글 순위, 플레이스 순위(광고 제외 70위까지)를
한 번에 모아 엑셀에 주마다 쌓는 프로그램입니다. 지난주와 비교해 오르고 내린 것도 표시됩니다.


■ 처음 한 번 (20분쯤)

1. 압축 풀기
   받은 「키워드순위추적.zip」 을 오른쪽 클릭 → 「압축 풀기」.
   「키워드순위추적」 폴더가 생기면 됩니다. 바탕화면처럼 찾기 쉬운 곳에 두세요.

2. 파이썬 설치 (이미 있으면 건너뜀)
   python.org 에서 내려받아 설치합니다.
   설치 첫 화면 아래 「Add python.exe to PATH」 칸을 꼭 체크하세요.
   → 이걸 안 하면 다음 단계에서 「파이썬이 없습니다」가 뜹니다.

3. 설치.bat 더블클릭
   1~2분 걸립니다. 「설치 완료」가 뜨면 창을 닫으세요.

4. 설정 3개 채우기 (오른쪽 클릭 → 「연결 프로그램」 → 메모장)
   · 설정_키워드.txt      재고 싶은 키워드를 한 줄에 하나씩 (예: 원주pt)
   · 설정_블로그.json     센터 이름, 플레이스 번호, 선생님 블로그 아이디
                          (안에 적힌 「_설명」 을 보고 따옴표 안만 바꾸세요)
   · _네이버광고_API.json  네이버 검색광고 API 열쇠 3개 — 검색량을 재는 데 씁니다.
                          비워 두면 검색량만 0 으로 나오고 순위는 그대로 잽니다.


■ 매주

5. 실행.bat 더블클릭
   6~8분 걸립니다. 「[완료]」 가 보이면 같은 폴더의 키워드순위표.xlsx 를 여세요.
   날짜마다 시트가 하나씩 쌓입니다.


■ 업데이트

따로 하실 것 없습니다. 실행.bat 을 켤 때마다 자동으로 최신 버전이 됩니다.
설정 3개와 지난 기록·엑셀은 업데이트가 건드리지 않습니다.
